# Банк стартовых палитр

Зачем этот файл: до сих пор акцент почти всегда выбирался с нуля в районе
"приглушённый синий/зелёный/фиолетовый", и палитра — единственная ось
отличия между приложениями, которую вообще варьировали. Здесь — набор
готовых **исходных наборов тонов** (не готовых `colors.ts`), из которых
можно оттолкнуться, чтобы диапазон оттенков и настроений был шире, чем
"ещё один приглушённый пастельный".

**Как использовать:**

1. Возьми набор ниже (или, если ни один не подходит по настроению
   приложения, — придумай свой в том же духе, не обязательно строго
   выбирать из списка).
2. Всё равно свериться с `DESIGN_REGISTRY.md` — набор ниже даёт **сырьё**
   (тона), а не готовое решение конфликта с 46+ приложениями портфеля. Один
   и тот же набор можно превратить в разные `accent`, если взять из него
   разный тон под акцент.
3. Разложи тона по ролям `src/theme/colors.ts` (`background`, `backgroundAlt`,
   `surface`, `surfaceAlt`, `border`, `ink`, `inkMuted`, `inkFaint`, `accent`,
   `danger`, `success`) — набор ниже почти никогда не даёт готовые роли 1:1:
   - Самый светлый/нейтральный тон → `background`/`surface` (если он ярче
     нейтрального белого/кремового — не бери его буквально, приложение
     остаётся преимущественно светлым и приглушённым; освети/обесцветь его
     ещё сильнее для фона, а исходный тон используй как `surfaceAlt` или
     подложку под hero-виджет).
   - Самый насыщенный/тёмный тон → `accent` (или `ink`, если он тёмно-
     нейтральный, не цветной).
   - Промежуточные тона → `secondary`-акцент для градиента hero-виджета
     (`AnimatedRing`/`ArcGauge`), категориальные цвета донат-чарта, или
     `success`/`danger`, если по смыслу подходят (зелёный/красный сектор).
   - Если в наборе нет спокойного нейтрального тона для `border`/`inkMuted` —
     возьми нейтральный серый/тёплый-серый вне набора, приглушённый, не
     конкурирующий по насыщенности с акцентом.
4. Яркие/неоновые наборы (Cyber Punk, Neon Electric, Purple Sunset, Cosmic
   Grape) — это сырьё для **акцента и hero-градиента**, не для фона: фон всё
   равно остаётся светлым и приглушённым (см. правило "Палитра —
   профессиональная, преимущественно светлая" в `CLAUDE.md`), яркость идёт в
   `accent`/`AnimatedRing`-градиент/бейджи, не в `background`/`surface`.
5. Один и тот же набор не использовать дважды в портфеле — после выбора он
   считается занятым так же, как обычный акцент (проверка по
   `DESIGN_REGISTRY.md`, не по этому файлу).

## Наборы

Пастельные / приглушённые:

- **Розовая пастель** `#FFC7C7` `#FFE2E2` `#F6F6F6` `#8785A2` — мягкий
  розово-лавандовый, `#8785A2` (приглушённый серо-фиолетовый) как акцент,
  `#FFC7C7`/`#FFE2E2` как тёплая подложка hero-карточки, не фон целиком.
- **Тусклая палитра** `#E8ECF1` `#B5CFD8` `#7393A7` `#6C737E` — холодный
  припылённый серо-голубой, весь набор уже приглушён; `#7393A7`/`#6C737E`
  под акцент/ink, `#E8ECF1` под фон почти напрямую.
- **Sage Garden** `#F7F4ED` `#C7D3C0` `#8FA28A` `#C8A96B` — тёплый
  нейтральный + шалфейный + горчичный акцент `#C8A96B` как альтернатива
  зелёному, если сам шалфей `#8FA28A` слишком близко к FridgeChef/Planti.
- **Modern Slate** `#F2F2ED` `#7CD5C7` `#118AB2` `#464B71` — нейтральный
  тёплый фон, бирюзово-синий акцент `#118AB2`, `#464B71` (приглушённый
  индиго) под `ink`/тёмные акценты вместо чистого чёрного.

Природные / насыщенные, но не пастельные:

- **Свежая зелень** `#EAEFC4` `#9BDF46` `#25A55F` `#346473` — салатовый+
  зелёный+сине-стальной; `#25A55F` под акцент, `#346473` под ink/second,
  `#9BDF46` только как яркий категориальный/бейдж-тон, не фон.
- **Бирюзовая палитра** `#93E4C1` `#3BAEA0` `#118A7E` `#1F6F78` — узкий
  бирюзовый градиент, хорошо ляжет на `AnimatedRing` как gradient stop 1→2,
  `#118A7E`/`#1F6F78` под акцент/ink.
- **Eco Friendly Green** `#E8F5E9` `#A5D6A7` `#66BB6A` `#1B5E20` —
  классический светлый→тёмный зелёный градиент, мапится на роли почти
  напрямую (bg/surfaceAlt/accent/ink).
- **Coffee & Matcha** `#FFF7EB` `#F9F0E0` `#A2AB73` `#CC3A63` — тёплый
  кремовый фон + оливковый + неожиданный ягодный акцент `#CC3A63` для
  danger/badge вместо стандартного красного.

Холодные / технологичные:

- **Холодная палитра** `#6FE7DD` `#3490DE` `#6639A6` `#521262` — циан→синий
  →фиолетовый градиент, хорош для hero-градиента (ring/arc), `#521262` под
  тёмный акцент/ink, только если в реестре ещё свободен фиолетовый сектор.
- **Classic Corporate Blue** `#E3F2FD` `#90CAF9` `#2196F3` `#0D47A1` —
  нейтральный "прямой" синий градиент — использовать с осторожностью,
  синих оттенков в портфеле уже много (Apexify/AquaTask/GasManager/
  DrinkReminder), сверяться с реестром обязательно.
- **Deep Ocean Tech** `#091540` `#1B2CC1` `#7692FF` `#ABD2FA` — тёмно-
  чернильный navy + яркий синий; годится под приложение с тёмной темой по
  умолчанию (как DreamLog/ColorMatch) — `#091540` под фон тёмной темы,
  `#7692FF` под акцент, `#ABD2FA` под текст на тёмном.
- **Nordic Winter Blue** `#3368A0` `#66A3BF` `#C8DFDB` `#F2EFE7` — тёплый
  крем `#F2EFE7` под фон, холодный синий `#3368A0` под акцент — контраст
  тёплого фона с холодным акцентом, не паттерн, который уже встречается.
- **Cyber Amber** `#224248` `#325E6A` `#44A1A4` `#FF9A00` — тёмный
  сине-зелёный + янтарный акцент `#FF9A00`, необычная неоновая пара для
  приложения с тёмной темой по умолчанию.

Яркие / неоновые (только акцент+hero-градиент, фон остаётся светлым):

- **Cyber Punk Light** `#C4F7CA` `#D8FFC5` `#92EEFF` `#30AFFF` — салатово-
  циановый, `#30AFFF` под акцент, остальное — категориальные тона, не фон.
- **Neon Electric** `#FF9137` `#FFCC4D` `#FFFC8C` `#70FFD2` — тёплый
  оранжево-жёлто-мятный, годится как категориальная палитра донат-чарта
  целиком (4 явно разных тона), акцент — `#FF9137` приглушённый до фона.
- **Purple Sunset** `#8C56D4` `#DC95FF` `#FFBEFB` `#FFF4BF` — фиолетово-
  розовый закат, `#8C56D4` под акцент, `#FFF4BF` только как тёплый блик в
  hero, не фон целиком.
- **Cosmic Grape** `#4E1F6E` `#3E3E75` `#45A9A9` `#98E8DE` — тёмный
  фиолетово-бирюзовый градиент, под тёмную тему или под hero-градиент
  ring/arc на светлом фоне.

Тёплые / винтажные:

- **Тёплый закатный** (Warm Autumn Dust) `#F7EAE0` `#F9D2BA` `#5E3122`
  `#1D4533` — тёплый бежевый фон, терракотовый + неожиданный тёмно-зелёный
  `#1D4533` как акцент вместо самого очевидного терракотового.
- **Retro Summer** `#FDF0D5` `#E9C46A` `#E76F51` — тёплая песочно-терракотовая
  тройка, только 3 тона — добавить свой нейтральный тёмный под `ink`.
- **Berry Smoothie** `#5D3140` `#CF4173` `#F39399` `#F6D8BD` — ягодно-
  розовый, `#CF4173`/`#5D3140` под акцент/ink, `#F6D8BD` тёплый фон.
- **Burgundy & Gold** `#8B1E2D` `#E63946` `#F4D35E` `#457B9D` — бордовый+
  золото+неожиданный синий `#457B9D` как secondary — необычное сочетание
  тёплого акцента с холодным secondary вместо монохромной лесенки.
- **Dark Lavender Night** `#722F99` `#C5C1C1` `#FEE7C8` `#FF9292` — тёмно-
  лавандовый + тёплый персиковый, хорош под тёмную тему или мягкий
  светлый вариант с `#FEE7C8` под фон.
